# REGLAS DE NEGOCIO

Documento vivo.

Reglas oficiales:

- Utilidad sobre utilidad real.
- OT dividida en Comercial, Producción, Costos, Pagos Proveedores y Rentabilidad.
- Tipo de cambio editable únicamente por Administrador.
- Vendedor no puede visualizar costos internos.
- Liquidación únicamente cuando la OT esté cerrada y los costos completos.
