# ELANPET MASTER CONTEXT

## Proyecto

ELANPET es una plataforma web para la venta de muebles y accesorios para mascotas.

Tecnologías:

* React
* Vite
* Context API
* CSS propio
* Supabase (en integración)
* Vercel

---

## Objetivos

1. Catálogo administrable.
2. Carrito de compras.
3. Portal de veterinarias afiliadas.
4. Sistema de QR por afiliado.
5. Control de comisiones.
6. Seguimiento de pedidos.
7. Panel administrativo completo.
8. Gestión multimedia.
9. Compatible con móvil y escritorio.

---

## Roles

### Cliente

* Ver catálogo
* Agregar al carrito
* Enviar pedido
* Consultar seguimiento

### Veterinaria

* Ver QR afiliado
* Consultar ventas
* Consultar comisiones
* Ver estado de pagos

### Administrador

* Productos

## Reglas del Proyecto

* Todo debe funcionar en móvil primero.
* Formularios a pantalla completa en móvil.
* Imágenes grandes para productos.
* Galerías de imágenes por producto.
* UX tipo ecommerce moderno.
* No agregar módulos nuevos sin terminar responsive.
* Trabajar paso a paso.
* Compilar después de cada cambio.
* Hacer commit después de cada módulo estable.
